Projects / GeoSmart Advisor

GeoSmart Advisor

Scores a map location for a given type of business using live map data, a Julia scoring core and a local language model for the written report.

Source on GitHub ↗All projects

What it does

You pick a point on the map and a business category. GeoSmart pulls nearby data from OpenStreetMap, Foursquare and World Bank sources, scores candidate sites around that point, and returns a heatmap plus a written site report. The whole stack runs on free-tier infrastructure.

I rebuilt it from scratch after the original codebase was lost to a drive failure.

How data moves through it

Responses are cached in Upstash Redis for 24 hours; DuckDB is the embedded store.

Design decisions

  1. Math in Julia, words in the model

    Language models are unreliable at arithmetic. The Julia core computes every score deterministically, and Phi-3-mini only sees the finished numbers when it writes the report.

  2. Julia instead of NumPy for the scoring matrix

    Scoring 100 candidates takes under 180 ms in JIT-compiled Julia. The same workload took about 2.1 s in NumPy.

  3. Sequential stages that write to disk

    Each stage writes JSON and exits, which keeps peak memory under 420 MB. A concurrent fan-out ingests 3.8× faster but costs memory; the sequential mode gives up about 1.2 s. Concurrency is planned as an opt-in mode.

  4. WebGL for the heatmap

    Leaflet and Folium dropped to 12–18 FPS on large grids. deck.gl holds 60 FPS with more than 100,000 points.

  5. Penalize overconfident scores

    The scoring uses an asymmetric loss that weights overconfident predictions 1.5× heavier, so the tool errs toward caution when recommending a site.
