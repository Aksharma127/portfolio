What it does

A command-line C++ program that runs YOLOv8 object detection on a video file or a live webcam (V4L2). It draws bounding boxes and labels, shows per-frame latency, and can write an annotated MP4 or run headless. There is no Python or deep learning framework at runtime, only OpenCV.

How a frame moves through it

  1. CaptureVideo file or V4L2 webcam
  3. LetterboxResize to 640 px input, aspect ratio kept
  5. InferYOLOv8n ONNX through OpenCV DNN
  7. NMSCustom non-maximum suppression
  9. OutputBoxes and telemetry overlay; MP4 file or headless
