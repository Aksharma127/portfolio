Edge Video Analytics

YOLOv8 object detection on video in C++17 with OpenCV's DNN module and no Python at runtime.

Source on GitHub ↗All projects

What it does

A command-line C++ program that runs YOLOv8 object detection on a video file or a live webcam (V4L2). It draws bounding boxes and labels, shows per-frame latency, and can write an annotated MP4 or run headless. There is no Python or deep learning framework at runtime, only OpenCV.

How a frame moves through it

Benchmark (CPU, from the repo README)

MeasureValue
Test video768×432, 647 frames
Average inference latency336 ms
Fastest inference252 ms
Average total time per frame358 ms

That is about 3 frames per second on CPU. The build supports CUDA and FP16 through OpenCV; a GPU benchmark is the next step.
