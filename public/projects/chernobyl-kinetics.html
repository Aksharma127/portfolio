ChernobylKinetics

A point-kinetics reconstruction of the 1986 Chernobyl excursion, run across five what-if scenarios.

Source on GitHub ↗All projects

What it models

The reactor core is treated as a single point. That drops spatial detail but keeps the time-dependent physics that drove the accident. The state is 11 coupled ordinary differential equations:

  • neutron population n(t)
  • six groups of delayed-neutron precursors
  • iodine-135 and xenon-135 concentrations (xenon poisoning)
  • average fuel and coolant temperatures, which feed back into reactivity

Parameters come from the IAEA INSAG-7 report. The system is solved with DifferentialEquations.jl in a Jupyter notebook.

What the runs show

  1. The void coefficient drives the runaway

    Raising it (scenario C) increases the peak by about 37,000× over baseline. Positive void feedback is what turns a power rise into an excursion.

  2. The graphite tips trigger it

    With no graphite tips (scenario E) the SCRAM works and power falls immediately. Doubling the tip effect raises the peak about 62×.

  3. A slower SCRAM lowers the peak here

    In scenario B, Doppler feedback in the fuel has time to act before the tips add reactivity.

  4. Where the model stops being valid

    A lumped model has no way to represent the core breaking apart. Past that point its temperatures become physically impossible, so they mark core destruction rather than real values.
